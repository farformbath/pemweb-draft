Warasin.

"Because Your Mind Matters" — Platform berbasis AI untuk mendeteksi tingkat stres individu menggunakan analisis data gaya hidup, pola tidur, dan pengenalan ekspresi wajah.

Overview

  • Role Data Scientist & ML Engineer
  • Timeline Feb 2026 — Jul 2026

  • Tech Stack Python, Scikit-learn, TensorFlow, Streamlit
  • Context Capstone — Coding Camp powered by DBS Foundation

The Problem

Stres merupakan masalah kesehatan mental yang sering kali tidak terdeteksi hingga mencapai tahap yang serius. Banyak individu tidak menyadari tingkat stres mereka karena kurangnya tools yang aksesibel dan mudah digunakan.

Metode deteksi stres tradisional memerlukan kunjungan ke profesional kesehatan mental, yang sering kali mahal dan memakan waktu. Diperlukan solusi yang dapat memberikan insight awal tentang tingkat stres berdasarkan data yang mudah diakses.

Approach & Methodology

Warasin menggunakan dua pendekatan machine learning secara simultan: analisis data tabular (gaya hidup, pola tidur, aktivitas fisik) menggunakan algoritma klasifikasi, dan pengenalan ekspresi wajah menggunakan deep learning (computer vision).

Proses meliputi data preprocessing, feature engineering, model selection, hyperparameter tuning, dan deployment via Streamlit. Dataset diproses dari sleep health dan lifestyle survey, dikombinasikan dengan facial expression recognition model.

Key Features

psychology Stress Level Detection via Lifestyle Data
face Facial Expression Recognition
insights Interactive Data Visualization

The Solution

Warasin dibangun sebagai web application menggunakan Streamlit, memberikan interface yang intuitif dimana pengguna dapat memasukkan data gaya hidup mereka (jam tidur, aktivitas fisik, tekanan darah, dll) dan mendapatkan prediksi tingkat stres secara real-time.

Selain input manual, pengguna juga dapat menggunakan fitur facial expression recognition melalui webcam atau upload foto untuk mendapatkan analisis tambahan. Hasil prediksi ditampilkan dengan visualisasi yang jelas dan rekomendasi yang actionable.
