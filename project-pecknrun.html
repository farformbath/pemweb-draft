The Challenge

Platform pesan-antar makanan modern sering kali terkendala oleh latensi tinggi antar-halaman pada arsitektur SPA terpisah dan kompleksitas manajemen order bagi merchant. Merchant membutuhkan kemudahan operasional tanpa harus menavigasi menu yang berbelit-belit.

Tantangannya adalah membangun platform yang responsif layaknya Single Page Application murni, namun tetap mempertahankan kekokohan arsitektur backend Laravel, serta menyediakan asisten cerdas yang dapat menjawab analisis operasional penjualan secara instan.

Engineering Architecture

PecknRun dibangun menggunakan perpaduan teknologi mutakhir:

  • Laravel 13 & PHP 8.4: Menyediakan backend yang kokoh, sistem otentikasi Sanctum, otorisasi berbasis Spatie Permission, serta migrasi dan seeder database yang tangguh.
  • Inertia.js v3 Server Adapter: Menghubungkan Laravel langsung dengan komponen React tanpa perlu menulis boilerplate REST API, menghasilkan navigasi instan tanpa reload halaman penuh.
  • React 19 & TypeScript: Komponen antarmuka yang type-safe, cepat, modular, dan didesain menggunakan utility-first styling Tailwind CSS v4.
  • AI Operations Copilot (9Router): Integrasi modul AI conversational streaming yang terhubung dengan data penjualan, membantu merchant mengecek ringkasan transaksi, rekomendasi stok, dan tren pesanan.
  • Production Deployment: Dideploy mandiri di VPS Ubuntu dengan konfigurasi Nginx reverse proxy, PM2/Supervisor, SSL Let's Encrypt, dan domain aktif demopecknrun.web.id.
