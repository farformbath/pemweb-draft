PusatKost UNNES.

Platform ekosistem pencarian dan manajemen kos mahasiswa di sekitar Universitas Negeri Semarang (UNNES), didukung oleh asisten cerdas NESA (Natural Estate Smart Assistant) dengan kemampuan AI tool-calling instan.

Overview

  • Role Lead Full-Stack & AI Integration Engineer
  • Timeline Aug 2026 — Present
  • Status Live on Production
  • Live Demo pusatkostunnes.my.id
  • Tech Stack Laravel, Inertia.js, React, TypeScript, Tailwind CSS, Minimax-M3 / DeepSeek AI, Nginx, SSL

The Challenge

Mencari kos di kawasan kampus UNNES Gunungpati sering kali melelahkan karena informasi yang tersebar acak di media sosial, ketiadaan filter fasilitas yang valid, serta ketidakpastian harga dan ketersediaan kamar secara real-time.

Mahasiswa memerlukan solusi satu pintu yang intuitif, cepat, dan mampu memberikan rekomendasi berbasis bahasa alami (contoh: "Cari kos putri dekat FMIPA ber-AC budget di bawah 1 juta") tanpa harus mencari satu per satu.

Architecture & Intelligent Features

PusatKost UNNES dirancang dengan penekanan pada kecepatan akses, keandalan server, dan interaksi cerdas:

  • Asisten Virtual NESA (AI Tool-Calling): NESA dapat memahami pertanyaan pengguna dalam bahasa Indonesia alami, mengeksekusi tool query database secara real-time, dan mengembalikan kartu rekomendasi kos dalam waktu kurang dari 2 detik menggunakan optimasi context compaction.
  • Modern Full-Stack Stack: Mengadopsi arsitektur Laravel + Inertia.js + React (TypeScript) untuk meminimalkan beban rendering, didukung styling Tailwind CSS dengan switch tema gelap/terang adaptif.
  • Pengujian Kualitas & E2E Testing: Dilengkapi suite pengujian otomatis End-to-End untuk memverifikasi alur pencarian, filter, dan dialog asisten cerdas bebas regresi.
  • Infrastructure: Dikelola langsung di server Linux VPS dengan Nginx, HTTP/2, sertifikat SSL TLS 1.3, dan konfigurasi optimasi caching aset Vite.
